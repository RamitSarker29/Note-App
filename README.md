# Simple Note App

A beginner-friendly text editor built using Python and Tkinter.

## Features

* Create a new file
* Open existing text files
* Save notes as `.txt` files
* Simple and clean user interface
* Menu bar with File options

## Technologies Used

* Python
* Tkinter

## How to Run

1. Clone the repository
2. Open the project folder
3. Run:

```bash
python main.py
```

## Learning Objectives

This project helped me learn:

* Tkinter GUI development
* Functions in Python
* File handling (`open`, `read`, `write`)
* Menu bars and dialog boxes
* Building desktop applications
